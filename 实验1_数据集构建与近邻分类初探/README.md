# 机器学习上机实验01：数据集构建与近邻分类初探

## 图像数据采集与1-NN最近邻分类

---

## 一、实验内容

1. **数据采集**：使用爬虫从图库网站爬取 building 和 mountain 两类图像各 50 张
2. **数据预处理**：调整图像大小、划分训练/验证/测试集
3. **特征提取**：像素级特征展平
4. **最近邻分类**：分别使用 sklearn 和自行编写的 1-NN 分类器进行图像分类

---

## 二、文件结构

### 代码

| 文件 | 说明 |
|---|---|
| `爬虫.py` | 图像数据爬取 |
| `拆分.py` | 数据集划分（训练/验证/测试） |
| `explore.py` | 数据探索与可视化 |
| `1nn_model.py` | 1-NN 分类器（sklearn + 自行实现） |
| `model_evaluation.py` | 模型评估与性能分析 |

### 数据

| 路径 | 说明 |
|---|---|
| `data/building/` | 50 张建筑原始图像 |
| `data/mountain/` | 50 张山原始图像 |
| `data/processed/` | 预处理后的特征和标签数据（`.npy`） |

### 其他

| 文件 | 说明 |
|---|---|
| `机器学习上机实验01：数据集构建与近邻分类初探.pdf` | 实验指导文档 |

---

## 三、运行方式

```bash
# 1. 爬取图像
python 爬虫.py

# 2. 数据集划分
python 拆分.py

# 3. 训练与评估 1-NN 分类器
python 1nn_model.py

# 4. 模型评估
python model_evaluation.py
```
