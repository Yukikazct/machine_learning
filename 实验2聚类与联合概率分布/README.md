# 机器学习上机实验02：聚类与联合概率分布

---

## 一、实验内容

| 任务 | 内容 |
|---|---|
| 任务1 | 二维高斯分布采样与协方差矩阵可视化 |
| 任务2 | K-Means 聚类实现与分析 |
