# 机器学习上机实验05：线性回归-2

## 图像分类中的线性模型与正则化

---

## 一、实验内容

1. **图像数据标准化**：加载猫狗图像数据集并进行标准化预处理
2. **多项式基函数扩展**：对图像特征进行多项式基函数变换
3. **线性模型基准测试**：使用线性回归模型进行图像二分类（猫 vs 狗）
4. **正则化强度扫描**：对比不同 λ 值下 L2 正则化对分类性能的影响
5. **权重分布可视化**：分析不同正则化强度下的权重分布

---

## 二、文件结构

### 代码

| 文件 | 说明 |
|---|---|
| `图像数据标准化.py` | 图像加载、缩放与标准化 |
| `多项式基函数扩展.py` | 图像特征多项式扩展 |
| `线性模型基准测试.py` | OLS 线性分类器基准 |
| `正则化强度 扫描.py` | L2 正则化参数 λ 扫描 |
| `权重分布可视化.py` | 不同 λ 下权重分布可视化 |

| 路径 | 说明 |
