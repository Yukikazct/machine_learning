# 机器学习上机实验07：线性回归-4

## 偏差-方差权衡与OLS鲁棒性分析

---

## 一、实验内容

### 实验一：偏差-方差权衡
- 使用 10 阶多项式特征拟合 sin(2πx)
- 生成 50 个不同训练集（每个 20 样本）
- 测试 8 个岭回归正则化参数 λ
- 计算偏差²、方差和总误差的权衡关系

### 实验二：OLS对离群点的鲁棒性
- 构造二分类数据（类别 0 和类别 1）
- 对比无离群点和有离群点的决策边界偏移
- 分析 OLS 对离群点的敏感性
