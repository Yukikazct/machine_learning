# 机器学习上机实验09：梯度下降-1

## 泰勒展开、Hessian矩阵与梯度下降几何直观

---

## 一、实验内容

| 任务 | 内容 |
|---|---|
| 任务1 | 泰勒展开局部逼近验证 — 二阶泰勒近似与原函数对比 |
| 任务2 | 驻点分类 — 基于 Hessian 特征值判断极小值/极大值/鞍点 |
| 任务3 | 梯度下降轨迹可视化 — 等误差线与特征向量方向分析 |

---

## 二、实验要点

1. **泰勒展开**：二阶泰勒展开在展开点附近提供了对原函数的良好局部近似
2. **Hessian 特征值**：全正→极小值点；全负→极大值点；有正有负→鞍点
3. **特征向量**：Hessian 的特征向量指示误差曲面的主曲率方向，梯度下降沿最陡方向更新
